# Customer Segmentation using KMeans

This project performs customer segmentation using machine learning to group customers based on their characteristics.

## Technologies Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn

## Steps Performed
1. Data Cleaning
2. Handling Missing Values
3. Exploratory Data Analysis
4. Feature Scaling
5. Elbow Method
6. KMeans Clustering
7. Cluster Visualization

## Results
The dataset was segmented into **4 clusters** representing different customer groups based on age, work experience, and family size.
